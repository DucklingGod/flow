# Security policy

This repository is a local-only alpha and is not a bank, broker, custodian, tax-filing service, or regulated execution system. Do not use public issues to disclose credentials, backup files, passphrases, national IDs, account statements, or personal financial data.

Report a suspected vulnerability through the repository's private GitHub security-advisory channel. Include the affected version, route, safe diagnostic ID, and reproduction steps using the synthetic default plan. Do not attach real plan exports or encrypted backups.

The current security boundary and incident process are documented in `docs/SECURITY.md`, `docs/THREAT_MODEL.md`, and `docs/INCIDENT_RUNBOOK.md`. Account, cloud sync, household/advisor sharing, external AI, live retrieval, trading, transfers/payments, and tax filing remain disabled until their release gates are approved.

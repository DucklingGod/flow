# Flow Wealth Studio app

Thai-first, local-first wealth planning workspace built with React, TypeScript, Vite, Dexie, Zod, and Web Workers. Financial outputs are models from explicit assumptions, not forecasts or execution instructions.

```powershell
npm.cmd run dev -- --host 0.0.0.0
npm.cmd run test
npm.cmd run test:coverage
npm.cmd run build
```

Release 0.6 includes routed workspace views, mobile bottom navigation, Portfolio X-Ray, Life Canvas, Wealth Map, and a seeded Monte Carlo Scenario Studio. No real trading, banking, custody, or automatic rebalance endpoint is implemented.
